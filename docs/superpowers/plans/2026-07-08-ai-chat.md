# AI Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一个 Web 端全局投资组合 AI Chat，基于系统已有组合数据、价格快照和有限记忆回答当前页面临时对话。

**Architecture:** 采用独立页面、无状态 API、服务端上下文构造器三层结构。前端只保存当前页面 session 的消息，`POST /api/ai-chat` 在服务端读取可信投资数据、组装中文 prompt，并调用 Anthropic 兼容 `CHAT` 场景模型返回纯文本。

**Tech Stack:** Next.js App Router、React、Vitest、Testing Library、Drizzle ORM、`@anthropic-ai/sdk`、`zod`、OpenSpec。

## 数据与接口约定

```ts
type ChatRequest = {
  question: string;
  messages?: Array<{
    role: "user" | "assistant";
    content: string;
  }>;
};

type ChatResponse = {
  answer: string;
};

type ChatError = {
  error: string;
};
```

```ts
type PortfolioChatContext = {
  generatedAt: string;
  strategies: StrategyContext[];
  positions: PositionContext[];
  prices: PriceContext[];
  memories: MemoryContext[];
  limitations: string[];
};
```

固定限制建议：

- `question.trim()` 必须非空，最大 4000 字符。
- `messages` 最多保留最近 12 条。
- 单条历史 `content` trim 后最大 4000 字符。
- 只允许 `role` 为 `"user"` 或 `"assistant"`。
- 策略内容每条最多 1200 字符，最多 20 条策略。
- 每个 symbol 最近价格最多 10 条。
- 记忆最多 12 条，总内容最多 6000 字符，置顶优先、相关 symbol/strategy 优先、近期优先。
