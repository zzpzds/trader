# 策略解析 Prompt 优化设计

**日期：** 2026-05-19
**范围：** `apps/web/lib/parse-strategy.ts`

## 背景

当前策略解析使用英文 prompt，`content` 字段描述泛泛，导致模型输出冗长、语言不统一、缺乏针对性。用户要求输出精炼、中文、结构固定，并能从多参数对比脚本中自动选出最优参数。

## 方案选择

采用**方案 A**：仅修改 `parse-strategy.ts` 中的 system prompt、user message 和 `content` 字段描述。工具 schema 结构（`name/symbols/content`）保持不变，前端无需改动。

## 设计

### System Prompt（新增）

```
你是一名量化策略分析师。请用中文分析 Python 交易策略脚本，提取关键信息。
输出内容要精炼，不要重复代码，不要冗余描述。
若脚本中包含多组参数的回测对比结果，请选取收益表现最优的那组参数作为最终策略描述的依据。
```

### User Message（改为中文）

```
请分析以下 Python 交易策略脚本：

\`\`\`python
${script}
\`\`\`
```

### `content` 字段描述（更新）

`content` 为 markdown 字符串，固定包含以下段落：

| 段落 | 内容 | 条件 |
|------|------|------|
| **策略总结** | 1-3 句话概括核心逻辑 | 必填 |
| **采用参数** | 最优参数组合及选择依据（如最高年化、最大夏普比等） | 仅当脚本含多组参数对比时输出 |
| **涉及标的** | 所有股票代码及其在策略中的角色 | 必填 |
| **买卖规则** | 每支股票各自的买入条件和卖出条件 | 必填 |
| **切换逻辑** | 切换时机与依据；单一持仓则注明"无切换逻辑" | 必填 |

### 不变部分

- 工具 schema：`name`、`symbols`、`content` 三字段保持不变
- API 调用模式：tool_use，`tool_choice: { type: "auto" }`
- 前端渲染：无需修改（已支持 markdown）
- `ParsedStrategy` 接口：无需修改

## 验收标准

1. 解析单策略脚本：输出包含策略总结、涉及标的、买卖规则、切换逻辑（或"无切换逻辑"），无"采用参数"节
2. 解析含多参数对比脚本：输出包含"采用参数"节，明确列出选定参数及理由
3. 所有输出文字均为中文
4. `content` 长度明显短于当前输出（无冗余代码复述）
