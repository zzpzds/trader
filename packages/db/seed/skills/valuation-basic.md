# 基础估值方法速查

本技能用于在每日监控分析中，对持仓标的的**估值水平**做快速定位，辅助判断 reference_price 是否合理、当前价是高估还是低估。

## 一、常用相对估值指标

| 指标 | 公式 | 适用 | 不适用 |
|---|---|---|---|
| PE（市盈率） | 价格 / EPS | 盈利稳定的成熟公司 | 周期股顶部 / 亏损公司 |
| 远期 PE | 价格 / 预期 EPS | 成长稳定的行业龙头 | 业绩波动大、预测分歧大 |
| PB（市净率） | 价格 / 每股净资产 | 重资产 / 金融 / 周期股 | 轻资产、高商誉公司 |
| PS（市销率） | 市值 / 营收 | 成长期未盈利公司 | 已稳定盈利的公司 |
| EV/EBITDA | 企业价值 / EBITDA | 跨杠杆比较、并购定价 | 资本支出差异大的行业 |
| 股息率 | 年股息 / 价格 | 高分红蓝筹 / 公用事业 | 不分红的成长股 |

## 二、估值的三个比较维度

单一估值数字几乎没有意义，必须放在**比较语境**中：

1. **历史百分位**：当前 PE 处于自身近 5/10 年的什么分位？
   - < 20% → 低估区间
   - 20%–80% → 正常
   - > 80% → 高估区间
2. **行业横向**：与同行业可比公司相比，溢价 / 折价多少？为什么？
3. **基本面挂钩**：高 ROE 对应的 PB 应该高、低增长对应的 PE 应该低。脱离基本面的"便宜"通常是陷阱。

## 三、PEG 简化使用

PEG = PE / 盈利增速。

- PEG < 0.8：可能低估（前提：增长可持续）
- PEG ≈ 1：合理
- PEG > 1.5：定价已透支增长

> 增长率应取**未来 3 年复合增速预测**或**过去 2 年实际值**中较保守者，避免单年高基数的误导。

## 四、DCF 速算（粗估而非精算）

监控分析中**不需要**做完整 DCF。粗略框架：

```
内在价值 ≈ 自由现金流 × (1 + g) / (r - g)
  g：长期增长率（成熟公司 2%–4%）
  r：折现率（A 股可用 8%–10%）
```

只用于：

- 判断当前价相对常识的"中枢"偏离方向
- 识别"假便宜"（PE 低但 FCF 长期为负）

## 五、估值陷阱清单

| 陷阱 | 识别 |
|---|---|
| 周期顶部低 PE | 业绩处于历史峰值 + 行业景气见顶信号 |
| 减值前低 PB | 商誉 / 应收账款占净资产比例高 |
| 一次性收益拉低 PE | 利润表中"营业外收入"占比异常高 |
| 高分红不可持续 | 派息率 > 100% 或经营性现金流不足以覆盖股息 |
| 估值修复实际是增长崩塌 | 价格跌但 EPS 跌得更快 |

## 六、在本项目中的输出方式

监控分析涉及估值时，建议输出结构化字段：

```json
{
  "valuation_view": {
    "method": "PE",
    "current": 18.5,
    "history_percentile": "12%",
    "industry_median": 23,
    "verdict": "low",
    "caveats": ["近 4 季度净利润含一次性投资收益，扣非后 PE ≈ 26"]
  }
}
```

`verdict` 取值：`low` | `fair` | `high` | `inconclusive`。

## 七、与其他技能协作

- 与 **reference-price-management**：估值结论是建议调整 reference_price 的关键依据，但调整动作仍需用户确认。
- 与 **risk-checklist**：估值过高 + 集中度过高 → 风险叠加，severity 升级为 high。
- 与 **behavioral-finance**：警惕"低估值"沦为锚定，便宜不等于该买。

## 八、什么时候直接说"看不清"

数据不全（缺 EPS 预测、新上市无历史百分位）、行业切换、重大重组进行中——这些情况下应直接输出 `verdict: inconclusive`，**不要**为了给结论而硬给数字。
