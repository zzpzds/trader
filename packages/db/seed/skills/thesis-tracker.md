# 投资论文追踪：买入后的纪律系统

> 改写自 ai-berkshire/skills/thesis-tracker.md，保留方法论骨架，去除 slash command 与外部工具调用，适配为 trader 持仓监控上下文。

对当前持仓中的每个标的，请回忆 strategy 描述 / 用户笔记中的 thesis（如有），逐条核对最新数据是否仍支持，明确给出「仍成立 / 部分动摇 / 已破产」结论。

## 设计理念

买入理由不是装饰品，而是卖出纪律的来源。每次监控都要问：当初买入的核心判断是否仍然成立？如果 thesis 破产，不要用新的故事替换旧理由。

常见漂移句式需要警惕：

- “虽然原来的增长没发生，但估值也不贵。”
- “虽然护城河变弱，但短期反弹空间大。”
- “虽然管理层失信，但行业还是好行业。”

这些不是 thesis 追踪，而是合理化。

## 核心 thesis 模板

如果 strategy 或 memories 已有 thesis，直接引用；如果没有，先用当前资料反推并标注“推断版 thesis，置信度低”。

| 模块 | 内容 |
|------|------|
| 核心判断 | 这家公司为什么会在 3-5 年后更有价值 |
| 关键假设 | 收入、利润率、护城河、管理层、监管、资本配置 |
| 验证指标 | 每个假设对应可观察指标 |
| 红线 | 哪些事实出现后必须重估或退出 |
| 估值锚 | 买入时隐含的增长和回报假设 |

## 三态判定

| 状态 | 判定标准 | 动作 |
|------|---------|------|
| 仍成立 | 核心假设被最新数据支持，红线未触发，估值锚未明显恶化 | 继续持有；若赔率更好可讨论加仓 |
| 部分动摇 | 1-2 个假设边际弱化，但核心逻辑未破；或数据不足但出现黄灯 | 降低信心分，限制加仓，列出下次必须验证的数据 |
| 已破产 | 核心假设被证伪，红线触发，或管理层/商业模式发生根本变化 | 建议清仓或至少大幅减仓；不得用新故事替代旧 thesis |

硬规则：thesis 已破产时，价格便宜不是继续持有的理由；只有重新建立并通过完整买入 checklist 的新 thesis，才允许重新评估买入。

## 红线清单

| 红线条件 | 严重程度 | 触发后动作 |
|---------|---------|-----------|
| 管理层诚信问题：造假、重大关联交易、恶性稀释 | 致命 | 立即建议清仓 |
| 核心业务连续 2 个周期恶化且无可信解释 | 严重 | 降低仓位并重估 |
| 护城河被明确突破 | 严重 | 启动退出评估 |
| 监管政策根本改变商业模式 | 严重 | 重估内在价值 |
| 管理层非计划性大规模减持 | 警告 | 深入调查原因 |

## 健康度评分

| 评分 | 含义 | 建议动作 |
|:----:|------|---------|
| 9-10 | 所有假设成立，thesis 比买入时更强 | 可考虑加仓 |
| 7-8 | 核心假设成立，个别边际弱化 | 继续持有 |
| 5-6 | 1-2 个假设受损，但核心逻辑未变 | 持有但提高警惕 |
| 3-4 | 多个假设受损，论文基础动摇 | 考虑减仓 |
| 1-2 | 红线触发或核心假设破裂 | 强烈建议卖出 |
