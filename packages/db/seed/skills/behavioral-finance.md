# 行为金融偏差速查

本技能用于在每日监控分析中，识别**用户决策**与**市场情绪**两个层面可能存在的认知偏差，并给出去偏建议或反向信号提示。

## 一、为什么纳入行为金融

单人持仓监控的最大风险来自**纪律失守**而非分析失误：止损不执行、追涨杀跌、把成本价当锚点。LLM 分析需要主动识别这些偏差并提示用户。

## 二、用户层面常见偏差

| 偏差 | 表现 | 监控分析如何识别 | 建议 |
|---|---|---|---|
| 损失厌恶 | 不愿割肉、对盈利仓快速止盈 | 浮亏 > 15% 仍持有 + 未触发止损 | 提示"已超过常规容忍区间，确认是否仍认同原策略逻辑" |
| 锚定效应 | 把成本价 / 历史高点当作"该回到"的目标 | 用户在 memory / notes 中频繁提到成本价 | 提示"价格不会因为是你的成本价而回归，请使用 reference_price 作为基准" |
| 沉没成本谬误 | 因为已经亏了所以继续加仓摊薄 | 多次同向买入 + 浮亏扩大 | 提示"加仓决策应基于当前 EV，与历史成本无关" |
| 确认偏误 | 只关注利好新闻，忽略利空 | 新闻摘要全偏正面，但价格持续走弱 | 主动列出近 30 天**利空**新闻摘要 |
| 过度自信 | 仓位过度集中、加仓过快 | 单一持仓 > 35%（参见 risk-checklist） | 触发集中度风险提示 |
| 后视偏误 | "早知道就该……" | 在分析回顾里频繁出现条件式 | 关注未来决策，不复盘已发生事件 |
| 处置效应 | 太早卖出盈利仓、太久持有亏损仓 | 持仓盈亏分布右偏 | 检查止盈 / 止损规则是否对称 |

## 三、市场层面常见偏差

| 偏差 | 表现 | 信号 | 利用方式 |
|---|---|---|---|
| 反应不足 | 业绩超预期后股价缓慢消化 | SUE > 2σ、评级上调 | 顺势持有 1–3 个月 |
| 反应过度 | 短期暴跌后超跌反弹 | 连续跌停 / RSI(5) < 10 | 警惕反弹但不一定参与 |
| 羊群效应 | 板块同步暴涨暴跌 | 同板块相关性 > 0.8 | 反向考虑：极端一致时反向胜率提高 |
| 注意力效应 | 上涨明星股放天量 | 异常换手 > 3 倍均值 | 警惕高位接力，进入观察名单 |

## 四、情绪周期定位

```
恐慌 → 谨慎 → 乐观 → 兴奋 → 狂热 → 否认 → 恐慌
（底部）（修复）（中段）（顶前）（顶部）（早跌）（再底）
```

每次监控可输出当前情绪阶段的**主观判断**（基于成交量、估值百分位、新闻情绪），并标注当前阶段的常见错误：

- 狂热期 → 容易追高 → 提醒减仓 / 止盈
- 恐慌期 → 容易割肉 → 提醒区分流动性恐慌与基本面恶化

## 五、去偏机制（建议输出）

LLM 分析输出可使用以下结构：

```json
{
  "behavioral_flags": [
    {
      "type": "loss_aversion",
      "evidence": "持仓 600519 浮亏 18% 已 14 天，策略止损价为 -10%",
      "suggestion": "建议复核策略逻辑或执行止损，不要因情绪推迟"
    }
  ]
}
```

flag 仅作为提醒，**不直接触发交易**。

## 六、与本项目的衔接

- 与 **reference-price-management**：识别"想把参考价改到当前价"这一锚定偏差。
- 与 **risk-checklist**：损失厌恶 / 处置效应通常会绕过止损纪律，应在风险层面强制提示。
- 与 **memories**：当 memory 中存储了用户对某持仓的强烈情绪表达，分析时应主动提示偏差风险。

## 七、底线

LLM 分析对用户的去偏建议应**温和但坚定**：陈述事实、给出依据、由用户做决定。不要使用情绪化或评判性语言（如"你又错了"），但也不要为了讨好用户而省略提示。**有偏差就说，没有就不必硬找。**
