# 新闻脉搏：把新闻变成持仓影响判断

> 改写自 ai-berkshire/skills/news-pulse.md，保留方法论骨架，去除 slash command 与外部工具调用，适配为 trader 持仓监控上下文。

基于 trader 的新闻摘要 / 用户提供的新闻片段，请对每条新闻分类（直接打击业绩 / 长期 thesis 影响 / 仅噪音），仅前两类给出操作建议，第三类一句话带过。

## 适用场景

- 持仓相关股票出现新闻，但不确定是否影响基本面。
- 新闻很多，需要区分真信号和重复转述。
- 股价异动后，需要判断是业绩冲击、thesis 变化还是情绪噪音。

不适用：完整深度研究、财报逐项精读、长期 thesis 重建。

## 新闻三类分级

| 类别 | 判定标准 | 动作 |
|------|---------|------|
| 直接打击业绩 | 新闻会影响收入、利润率、现金流、监管成本、供给能力或重大客户 | 量化影响，判断是否触发减仓/清仓 |
| 长期 thesis 影响 | 新闻不一定立刻进财报，但会改变护城河、竞争格局、管理层可信度或行业终局 | 触发 thesis-tracker 式复核 |
| 仅噪音 | 对商业模式、现金流和 thesis 没有可验证影响 | 一句话带过，不给交易建议 |

## 噪音识别红旗

| 红旗 | 说明 |
|------|------|
| 媒体跟风 | 多篇报道只是重复同一来源 |
| 二手转述 | 没有公告、电话会、监管文件或一手采访 |
| 未具名消息源 | “知情人士”但无法交叉验证 |
| 标题党 | 标题夸大，正文没有新事实 |
| 与持仓无关 | 行业泛泛评论，不能落到该公司收入、成本或护城河 |
| 旧闻重炒 | 事实已被市场消化 |

## 影响判断框架

| 新闻 | 来源质量 | 类别 | 影响路径 | 证据 | 置信度 |
|------|---------|------|----------|------|--------|
|      | 一手 / 二手 / 未证实 | 业绩 / thesis / 噪音 | 收入 / 利润率 / 护城河 / 管理层 / 监管 | | 高 / 中 / 低 |

### 业绩影响

问：

- 会不会改变未来 1-4 个季度收入？
- 会不会改变毛利率、费用率或现金流？
- 是否影响关键客户、供应链、监管成本？
- 是否可量化？如果不能，写明“方向明确但无法量化”。

### thesis 影响

问：

- 是否证明原 thesis 的关键假设变强或变弱？
- 是否说明护城河被突破或变宽？
- 是否改变管理层可信度？
- 是否改变行业终局或监管边界？

## 行动建议纪律

- 只有“直接打击业绩”和“长期 thesis 影响”允许给动作建议。
- “仅噪音”不得建议买卖，只能说明为何忽略。
- 置信度低时，建议应是“等待确认信号”，而不是交易。

```markdown

| 新闻 | 分类 | 影响路径 | 置信度 | 建议 |
|------|------|----------|--------|------|

1.

### 可忽略噪音
1.

### 对当前 strategy 的影响

- 是否触发仓位动作：
- 接下来 7-30 天跟踪：
```
