# 财报精读：一手资料深度解读

> 改写自 ai-berkshire/skills/earnings-review.md，保留方法论骨架，去除 slash command 与外部工具调用，适配为 trader 持仓监控上下文。

若 strategy 含财报触发规则，或当前持仓在近 30 天内发布过财报，请按下面框架精读该财报，输出「超预期 / 符合 / 不及」结论 + 三层证据。

## 一手资料优先

优先级：

1. 公司公告、季报、年报、10-Q/10-K、earnings release、电话会原文。
2. 公司投资者关系材料。
3. 第三方摘要、新闻、研报。

二手信息可能过度概括、滞后或带立场。若只拿到二手信息，必须标注“一手资料不足”，降低结论置信度。

| 等级 | 特征 | 处理 |
|------|------|------|
| A | 完整原文和财务表可得 | 正常执行全部框架 |
| B | 只有部分原文或第三方汇总 | 标注来源等级，降低附注和语气分析权重 |
| C | 只有新闻或数据摘要 | 聚焦核心数字变化，结论保守 |

## 第一层：增长质量

| 指标 | 本期 | 上期 | 同比/环比 | 管理层指引 | 判断 |
|------|------|------|-----------|------------|------|
| 收入 | | | | | 量增 / 价增 / 一次性 |
| 毛利率 | | | | | 定价权 / 成本压力 |
| 营业利润率 | | | | | 经营杠杆 |
| 净利润 | | | | | 真实改善 / 会计扰动 |
| 用户、订单或销量 | | | | | 增长来源 |

检查重点：

- 增长来自核心业务还是一次性项目？
- 毛利率和经营利润率是否同步改善？
- 增长是否牺牲现金流、补贴或应收账款？
- 管理层是否下调未来指引？

## 第二层：现金流与资产负债表

| 指标 | 本期 | 上期 | 变化 | 关注点 |
|------|------|------|------|--------|
| 经营现金流 | | | | 是否跟上净利润 |
| 经营现金流 / 净利润 | | | | >100% 佳，<80% 警惕 |
| 资本开支 | | | | 维持性还是扩张性 |
| 自由现金流 | | | | 是否持续为正 |
| 现金及等价物 | | | | 安全垫 |
| 有息负债 | | | | 杠杆压力 |
| 应收账款 / 存货 | | | | 是否异常累积 |

红旗：

- 利润增长但经营现金流恶化。
- 应收账款增速显著高于收入。
- 存货持续堆积且未解释。
- 债务上升但投资回报不清楚。
- 资本化费用增加导致利润失真。

## 第三层：管理层 commentary

| 信号类型 | 具体表现 | 判断 |
|---------|---------|------|
| 坦诚 | 主动承认问题并解释原因 | 正面 |
| 清晰 | 战略表述具体、有量化目标 | 正面 |
| 模糊 | 大量使用“长期来看”“充满信心”但缺数据 | 红旗 |
| 转移 | 回避利润率、现金流、竞争问题 | 红旗 |
| 外部归因 | 把问题全部归咎于宏观或行业 | 红旗 |

必须追踪上一期承诺：

| 上期承诺 | 本期兑现情况 | 评价 |
|---------|-------------|------|
|         |             | 达标 / 部分达标 / 未达标 |

## 结论分级

| 结论 | 标准 |
|------|------|
| 超预期 | 核心业务增长质量提升、现金流同步改善、管理层指引更清晰 |
| 符合 | 大体符合 thesis，未出现重大红旗 |
| 不及 | 增长质量下降、现金流恶化、红旗出现或管理层回避关键问题 |
