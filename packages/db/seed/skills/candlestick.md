# K 线形态速查

本技能用于在每日监控分析中，结合最近 5–10 根日 K 线判断**反转 / 延续信号的强弱**，辅助决定是否触发买卖建议。**单一形态不构成交易信号**，需配合趋势位置、成交量、参考价位综合判断。

## 一、单根 K 线

| 形态 | 信号 | 判定要点 |
|---|---|---|
| 锤子线 Hammer | 看涨（出现在下跌末端） | 实体小且位于顶部，下影线 ≥ 2 倍实体，上影线极短 |
| 倒锤子 Inverted Hammer | 看涨（下跌末端） | 实体小且位于底部，上影线 ≥ 2 倍实体 |
| 流星 Shooting Star | 看跌（上涨末端） | 形态同倒锤子，但出现在上涨后 |
| 十字星 Doji | 中性 / 反转预警 | 开盘≈收盘，实体 ≤ 全幅 10%；高位 / 低位时反转概率提升 |
| 陀螺 Spinning Top | 中性 / 犹豫 | 实体小，上下影线均较长 |

## 二、双根组合

| 形态 | 信号 | 判定要点 |
|---|---|---|
| 看涨吞没 Bullish Engulfing | 强看涨 | 第二根阳线实体完全吞没前一根阴线实体，出现在下跌后 |
| 看跌吞没 Bearish Engulfing | 强看跌 | 阴线吞没前一根阳线实体，出现在上涨后 |
| 看涨孕线 Bullish Harami | 弱看涨 | 第二根阳线小实体被前一根大阴线包含 |
| 看跌孕线 Bearish Harami | 弱看跌 | 阴线小实体被前一根大阳线包含 |
| 刺透 Piercing Line | 看涨 | 阴线后出现阳线收在阴线实体中点之上（未吞没） |
| 乌云盖顶 Dark Cloud Cover | 看跌 | 阳线后阴线收在阳线实体中点之下 |

## 三、三根组合

| 形态 | 信号 |
|---|---|
| 早晨之星 Morning Star | 强看涨反转（阴 + 小实体 + 阳，第三根收复阴线一半以上） |
| 黄昏之星 Evening Star | 强看跌反转（阳 + 小实体 + 阴） |
| 三白兵 Three White Soldiers | 强看涨延续（连续三根阳线，依次收高） |
| 三只乌鸦 Three Black Crows | 强看跌延续（连续三根阴线，依次收低） |

## 四、识别注意事项

1. **必须看趋势位置**：吞没 / 锤子 / 星形等反转形态只在**前期已有趋势**时才有意义。横盘中的"锤子"通常无信号。
2. **成交量配合**：看涨反转形态在底部应伴随**温和或显著放量**；缩量反转可信度低。
3. **形态等级**：三根 > 双根 > 单根，吞没 / 三星 / 三兵的可信度高于十字星 / 陀螺。
4. **A 股特殊性**：涨跌停板会扭曲实体长度判断；遇到一字板 / T 字板时，K 线形态结论失效。
5. **避免组合冲突**：若同一日出现"看涨吞没 + 顶部十字星"等冲突信号，应判定为不确定，**不应基于 K 线形态触发交易**。

## 五、在本项目中的使用方式

策略脚本传入持仓的近 N 日价格快照后，分析阶段可：

- 描述最近 1–3 根 K 线的形态名称（如"日 K 出现底部锤子线，下影 2.3 倍实体"）。
- 把形态信号作为**加权依据**而非决策依据：例如"参考价已触发，但顶部出现看跌吞没，可考虑分批建仓而非一次满仓"。
- 当形态与策略 reference_price 信号冲突时，**优先服从 reference_price**，把 K 线作为时点选择参考。

## 六、信号汇总约定

输出建议格式：

```
candlestick: <形态名> @ <日期> -> <bullish|bearish|neutral>
```

例：`candlestick: 看涨吞没 @ 2026-06-05 -> bullish`。多个形态冲突时输出 `neutral` 并在备注中说明。
