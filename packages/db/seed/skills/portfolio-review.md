# 组合管理：从单标的切换到整体持仓

> 改写自 ai-berkshire/skills/portfolio-review.md，保留方法论骨架，去除 slash command 与外部工具调用，适配为 trader 持仓监控上下文。

请把分析对象从单 strategy 切换到「全部持仓」视角，按集中度 / 质量 / 估值三维度评估组合是否需要再平衡，给出具体调整建议（包含数字）。

## 一句话原则

研究公司解决“这家公司好不好”，管理组合解决“这些持仓放在一起是否更好”。单个标的看起来合理，不代表组合结构合理。

|      |          |      |      |      |        |      |             |

若缺少全账户数据，必须标注“组合视角数据不足”，只对可见持仓做局部判断。

## 集中度阈值表

| 指标 | 建议范围 | 红线 | 判断 |
|------|---------|------|------|
| 第一大持仓占比 | < 40% | > 50% 且非高确定性核心仓 | 是否单点风险过大 |
| 前三大持仓占比 | 50%-80% | > 85% 或 < 35% | 是否过度集中或过度分散 |
| 单行业占比 | < 50% | > 60% | 是否暴露于同一监管/周期/需求 |
| 单一宏观因子 | < 60% | > 70% | 是否同受利率、汇率、AI capex 等驱动 |
| 现金占比 | 10%-30% 视市场环境 | 极端满仓或长期空仓 | 是否保留机会成本弹性 |

## 质量分层框架

| 层级 | 特征 | 处理 |
|------|------|------|
| 一流 | 高 ROIC、高现金流质量、护城河变宽、管理层可信 | 可作为核心仓，但仍看估值和集中度 |
| 中等 | 生意可理解但护城河、现金流或管理层有短板 | 限制仓位，等待证据改善 |
| 留待去化 | thesis 动摇、质量下降、替代机会更好 | 列入减仓或清仓候选 |

组合中一流公司过少，说明组合质量不足；留待去化仓位过大，说明纪律失效。

## 估值分层框架

| 层级 | 特征 | 处理 |
|------|------|------|
| 低估 | 保守内在价值下仍有安全边际 | 可承接新增资金或再平衡加仓 |
| 合理 | 回报主要来自业绩增长 | 持有，少做动作 |
| 偏贵 | 乐观假设才有回报 | 限制加仓，考虑换入更高赔率 |
| 高估 | 风险补偿不足或靠情绪支撑 | 减仓或退出 |
