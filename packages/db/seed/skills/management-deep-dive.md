# 管理层纵深评估：买股票就是买人

> 改写自 ai-berkshire/skills/management-deep-dive.md，保留方法论骨架，去除 slash command 与外部工具调用，适配为 trader 持仓监控上下文。

请对当前持仓中权重较大的标的（≥ 总仓 20%）的管理层进行四维评估（履历 / 持股 / 资本配置 / 关键决策），输出红旗清单 + 综合评分 1-5。

## 设计理念

管理层评估不能停留在简历、名气和采访金句。要看行为：承诺是否兑现，资本是否配置得当，困难时期是否诚实，股东利益是否被尊重。

## 四维评分框架

| 维度 | 权重 | 评分(1-5) | 关键问题 |
|------|:----:|:---------:|----------|
| 履历与能力圈 | 20% | | 是否懂这门生意，是否有穿越周期经验 |
| 持股与利益一致 | 20% | | 是否像所有者一样思考 |
| 资本配置记录 | 35% | | 每赚一块钱，是否能变成更多价值 |
| 关键决策与诚信 | 25% | | 困难时期是否诚实、理性、长期 |

综合评分：

- 5：可作为核心仓加分项。
- 4：可信任，但仍需监控。
- 3：中性，不能因为管理层加仓。
- 2：存在明显瑕疵，限制仓位。
- 1：诚信或治理红旗，建议退出。

## 资本配置评估

| 类型 | 应看指标 | 好决策 | 坏决策 |
|------|---------|--------|--------|
| 回购 | 回购价、当时估值、后续价值 | 低估时回购，高估时停止 | 高估时为 EPS 买单 |
| 派息 | 分红率、FCF 覆盖 | 无好机会时返还现金 | 借债分红或影响再投资 |

困难时期重点看：

- 是否主动承认问题，而不是全部归因外部环境。
- 是否保护现金流和长期竞争力。
- 是否牺牲少数股东利益。
- 是否在危机中做出高质量资本配置。

## 管理层红旗清单

- 财务造假、误导性披露或关键数据前后矛盾。
- 频繁发股、期权过度、长期稀释股东。
- 薪酬异常高且与业绩脱钩。
- 关联交易复杂且缺乏公允解释。
- 高价并购、商誉暴雷、盲目多元化。
- 关键岗位持续流失。
- 管理层大规模减持且解释牵强。
- 面对尖锐问题长期回避。
