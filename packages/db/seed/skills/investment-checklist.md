# 巴菲特价值投资买入前六关 Checklist

> 改写自 ai-berkshire/skills/investment-checklist.md，保留方法论骨架，去除 slash command 与外部工具调用，适配为 trader 持仓监控上下文。

当 strategy 的 buy 规则即将触发或刚触发时，请按下面六关逐项打分，任一关给 ★1 即标注「不通过，原因：…」并建议放弃本次买入。

## 信息充足度

| 等级 | 判断标准 | 处理方式 |
|------|---------|---------|
| A | 上市多年、财务和经营数据充裕 | 正常执行六关，但警惕共识陷阱 |
| B | 数据有限，需要合理推算 | 每个推算项标注置信度 |
| C | 信息极度稀缺 | 不勉强填满表格，结论标注“数据不足，暂不通过” |

## 第一关：能力圈

核心问题：这个公司怎么赚钱？客户是谁？为什么客户愿意付钱？未来 5-10 年哪些变量会改变结果？

| 评分 | 标准 |
|------|------|
| ★5 | 能清楚解释商业模式、关键变量和反身性风险 |
| ★4 | 能解释主要收入、成本、客户和竞争格局 |
| ★3 | 大致理解，但关键变量仍有不确定 |
| ★2 | 只能复述概念，无法解释单位经济 |
| ★1 | 赚钱方式说不清 |

硬性否决：连赚钱方式都说不清，直接标记“不在能力圈”。

## 第二关：经济特征

| 指标 | 参考标准 | 判断 |
|------|---------|------|
| ROE / ROIC | 长期 >15% 优秀，>20% 卓越 | 是否可持续 |
| 毛利率 | >40% 常暗示定价权 | 是否稳定 |
| 自由现金流 | 持续为正且接近净利润 | 利润质量 |
| 资本开支强度 | 轻资产优于重资产 | 增长是否烧钱 |
| 负债水平 | 有息负债 / 净利润 < 3 年 | 财务韧性 |

| 评分 | 标准 |
|------|------|
| ★5 | 高 ROIC、高现金转化、低负债，跨周期稳定 |
| ★4 | 大多数指标优秀，个别波动可解释 |
| ★3 | 指标普通但仍可接受 |
| ★2 | 现金流差或资本开支吞噬利润 |
| ★1 | 长期赚不到现金或杠杆不可承受 |

硬性否决：连续多年自由现金流为负且看不到改善。

## 第三关：护城河

| 护城河类型 | 证据 | 趋势 |
|-----------|------|------|
| 品牌 / 定价权 | 提价后需求是否稳定 | 变宽 / 稳定 / 变窄 |
| 转换成本 | 客户迁移成本和续约率 | 变宽 / 稳定 / 变窄 |
| 网络效应 | 用户越多是否越有价值 | 变宽 / 稳定 / 变窄 |
| 成本 / 规模优势 | 单位成本是否低于同行 | 变宽 / 稳定 / 变窄 |
| 技术 / 专利壁垒 | 是否可防止复制 | 变宽 / 稳定 / 变窄 |

| 评分 | 标准 |
|------|------|
| ★5 | 多重护城河叠加且变宽 |
| ★4 | 至少一条强护城河且稳定 |
| ★3 | 有护城河但深度一般 |
| ★2 | 护城河正在被侵蚀 |
| ★1 | 无明显护城河 |

硬性否决：核心护城河已被证据证明失效。

## 第四关：管理层

| 检查项 | 评估 |
|--------|------|
| 诚实度 | 承诺是否兑现，坏消息是否坦诚 |
| 资本配置 | 回购、分红、并购、再投资是否创造价值 |
| 股东导向 | 持股、薪酬、稀释、关联交易 |
| 所有者心态 | 创始人精神或长期治理机制 |
| 组织韧性 | CEO 离开后是否还能运转 |

| 评分 | 标准 |
|------|------|
| ★5 | 诚实、长期、资本配置卓越 |
| ★4 | 大方向可靠，偶有瑕疵 |
| ★3 | 中性，缺少强证据 |
| ★2 | 多次承诺落空或治理弱 |
| ★1 | 严重诚信问题 |

硬性否决：财务造假、重大关联输送、恶性稀释或管理层诚信破产。

| PE / 前瞻 PE | | | |
| PB | | | |
| FCF Yield | | | |
| 内在价值区间 | | | |
| 安全边际 | | | |

| 评分 | 标准 |
|------|------|
| ★5 | 高确定性且价格显著低于保守内在价值 |
| ★4 | 有安全边际，赔率清楚 |
| ★3 | 价格合理但不便宜 |
| ★2 | 乐观假设才有收益 |
| ★1 | 明显高估或无法估值 |

## 第六关：仓位与风险纪律

| 问题 | 判定 |
|------|------|
| 单仓是否超过风险承受上限 | 是 / 否 |
| 买入后是否影响组合集中度 | 是 / 否 |
| 下跌 30% 时是否仍能持有 | 是 / 否 |
| 是否存在更高确定性的替代机会 | 是 / 否 |

| 评分 | 标准 |
|------|------|
| ★5 | 仓位、赔率、组合风险都匹配 |
| ★4 | 风险可控，有明确止错条件 |
| ★3 | 可小仓试错 |
| ★2 | 仓位或回撤承受力不匹配 |
| ★1 | 情绪化买入或组合风险失控 |

硬性否决：无法写清“买错后如何承认错误”。
