# 参考价（reference_price）管理

本项目的策略对象上有一个 `reference_price` 字段，作为**买卖触发的基准价**。本技能定义它的语义、何时该更新、何时不该动，避免分析时对参考价的误用。

## 一、参考价是什么

**定义**：策略当前认定的"合理基准价"，触发买卖判断的锚点。
**不是**：成本价、最近成交价、历史最高/最低。
**典型用法**：

- 当前价 < reference_price × (1 - buy_threshold) → 触发买入信号
- 当前价 > reference_price × (1 + sell_threshold) → 触发卖出信号

`buy_threshold` / `sell_threshold` 由策略脚本自行定义（如 5% / 10%）。

## 二、参考价的来源

参考价**最初由用户写策略时设定**，可能基于：

- 估值锚（DCF 内在价值、PB × 合理 ROE）
- 技术锚（关键支撑位、20 日均线、前低）
- 心理锚（用户愿意买入的价位）

LLM 分析时**不要**自行假设参考价的来源，只把它当作"用户已认定的基准"使用。

## 三、何时应建议更新参考价

仅在以下情境下，分析输出可以**建议**用户调整 reference_price（最终是否更新由用户决定）：

| 情境 | 建议方向 |
|---|---|
| 公司发生重大正面变化（业绩超预期、新业务释放） | 上调 |
| 公司基本面明显恶化（业绩暴雷、行业塌陷、合规问题） | 下调 |
| 大盘 / 板块整体重定价（牛熊切换、估值中枢迁移） | 双向 |
| 距离上次设定 ≥ 6 个月，且公司财报已更新 2 期以上 | 重新评估 |

**输出格式**：

```
reference_price_review:
  current: 12.50
  suggested: 14.00
  rationale: "Q3 净利润同比 +45%，远超指引；且行业龙头估值整体上移"
  confidence: medium
```

## 四、何时**不应**动参考价

- **当前价短期偏离参考价**（这正是参考价存在的意义——偏离触发交易）
- 单日大涨 / 大跌但无基本面变化
- 仅因用户浮亏过大而想"下调止损"——这是改写规则而非更新基准
- 财报 / 新闻尚未发布，仅基于猜测

> 警惕：把参考价"调到当前价附近"是**最常见的纪律失守**，等于把基准锚定到情绪。LLM 分析必须主动识别并劝阻。

## 五、参考价 vs 止损价

| 字段 | 角色 | 修改频率 |
|---|---|---|
| `reference_price` | 买卖触发基准 | 低（季度级，重大变化才动） |
| 止损价（策略脚本内） | 风险管理硬底线 | 视策略而定，常随成本动态上移 |

两者**独立**，不要混用。LLM 分析输出建议时应分开表达。

## 六、分析输出中的引用规范

每次监控分析涉及参考价时，建议明确引用：

```
当前价 = 11.20，reference_price = 12.50
偏离 = -10.4%，已触发 buy_threshold = 8%
建议：触发分批买入信号；同时评估近期是否有基本面恶化（见风险体检）
```

如果分析判断 reference_price 本身需要更新，**单独输出 `reference_price_review` 块**，不要在交易建议里直接覆盖。

## 七、与其他技能的协作

- 与 **risk-checklist**：当 risk-checklist 输出 `stop_loss_triggered` 时，止损动作优先于 reference_price 触发的买入信号。
- 与 **valuation-basic**：估值结论可以作为调整 reference_price 的依据，但 LLM 不能跳过用户直接更新。
- 与 **candlestick**：K 线形态影响时点选择，不影响 reference_price 本身。

## 八、底线

LLM 在监控分析中**永远不能**在没有用户确认的情况下"自动"把 reference_price 改写到当前价。所有调整建议必须显式输出在 `reference_price_review` 字段中等待用户审阅。
