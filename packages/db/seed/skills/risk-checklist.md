# 持仓风险体检清单

本技能用于每日监控分析中，对**已有持仓**做 5 维度风险扫描。一旦命中红线，建议优先输出风险提示而非进一步加仓。

## 一、仓位集中度

| 指标 | 正常 | 警戒 | 红线 |
|---|---|---|---|
| 单一持仓占总市值 | < 20% | 20%–35% | > 35% |
| 单一行业占总市值 | < 35% | 35%–50% | > 50% |
| 持仓数量 | 5–15 | 3–4 或 16–25 | < 3 或 > 25 |

> **触发条件**：任意红线 → 输出 `concentration_risk` 标签，建议"减仓 / 不再加仓"。

## 二、回撤与盈亏幅度

判断**当前持仓**相对参考价或成本价的浮亏：

- 浮亏 0%–10%：正常波动区间，不触发。
- 浮亏 10%–20%：进入警戒。检查策略脚本是否设置了硬止损。
- 浮亏 > 20%：红线。**必须**输出风险提示，要求用户复核：
  1. 标的基本面是否恶化（业绩 / 政策 / 行业）？
  2. 当前价是否跌破策略 reference_price 的止损位？
  3. 是否存在加仓摊薄成本的合理依据？

> 浮盈方向：盈利 > 30% 时建议输出 `take_profit_consider`，提醒考虑分批止盈或上移止损位。

## 三、止损纪律

每次分析必须确认：

- 策略脚本是否定义了**明确的止损价 / 止损规则**？没有则输出 `no_stop_loss` 警告。
- 当前价是否已**跌破止损价**？是则强制输出 `stop_loss_triggered`，建议立即评估卖出。
- 止损后是否仍持有？连续 2 个监控周期持有但未止损 → `stop_loss_violation`。

不要因短期反弹理由推迟止损执行。**已破止损价是事实，不是观点。**

## 四、流动性风险

| 信号 | 含义 |
|---|---|
| 近 5 日日均成交额 < 5000 万元（A 股） | 流动性偏弱，遇极端行情可能滑点严重 |
| 持仓市值 / 日均成交额 > 5% | 自身仓位已对盘面有冲击，难以快速出清 |
| ST / *ST / 退市风险警示 | 直接输出 `delisting_risk`，建议清仓 |
| 停牌中 | 输出 `suspended`，不做交易建议 |

## 五、宏观与事件风险

监控分析时如检测到以下情境，应在结论中显式提示：

- **财报披露窗口**（前后 1 周）：业绩不确定性高，避免重仓加仓。
- **解禁 / 限售股到期**：检查近 30 天是否有大额解禁。
- **政策事件**：行业监管、关税、地缘事件。
- **指数级别风险**：大盘 20 日均线下行 + 跌破半年线 → 输出 `market_regime_bearish`，建议整体降低仓位。

## 六、输出格式约定

风险扫描结果应汇总为标签数组：

```json
{
  "risk_flags": ["concentration_risk", "stop_loss_triggered"],
  "severity": "high",
  "action_hint": "建议减仓 50% 或直接止损"
}
```

`severity` 取值：`low` | `medium` | `high`；只要任一红线触发即为 `high`。

## 七、与策略脚本的边界

本清单**不替代**策略脚本中的止损 / 加仓逻辑，而是在 LLM 分析层做**第二道防线**：策略脚本可能因 bug、数据延迟、参考价过时而漏报，体检清单确保用户至少看到一次风险提醒。

最终交易动作仍由用户在 web 上手动确认，本技能输出的所有标签均为**建议性**。
