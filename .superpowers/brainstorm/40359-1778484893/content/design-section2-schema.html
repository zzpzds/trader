设计第二节：数据库 Schema

PostgreSQL，7 张核心表。pg-boss 任务队列自动管理自己的表，不需要手动维护。

strategies 策略定义
id uuid PK
name text
description text
config jsonb ← 完整策略 DSL
created_at timestamptz
updated_at timestamptz
backtests 回测记录
id uuid PK
strategy_id uuid FK → strategies
start_date date
end_date date
initial_capital numeric
status text ← pending/running/done/failed
results jsonb ← 指标 + 权益曲线
created_at timestamptz
portfolios 持仓组合（Phase 2）
id uuid PK
strategy_id uuid FK → strategies
name text
mode text ← 'paper' | 'live'
initial_capital numeric
status text ← active/paused/closed
started_at timestamptz
positions 当前持仓（Phase 2）
id uuid PK
portfolio_id uuid FK → portfolios
symbol text
total_shares numeric
avg_cost numeric ← 均价，加仓后更新
addition_count int ← 已加仓次数
opened_at timestamptz
trades 交易记录（Phase 2）
id uuid PK
portfolio_id uuid FK → portfolios
symbol text
action text ← 'buy' | 'sell'
shares numeric
price numeric
source text ← 'auto'(模拟) | 'manual'(实仓)
executed_at timestamptz
notifications 站内通知（Phase 2）
id uuid PK
type text ← 'signal' | 'info' | 'warning'
title text
body text
strategy_id uuid FK nullable
portfolio_id uuid FK nullable
read boolean
created_at timestamptz
price_cache 行情缓存，两个服务共享读写
symbol text ← PK 联合索引
timeframe text ← '1d' | '1h' | '15m'
ts timestamptz ← PK 联合索引
open high low close volume numeric
📌 Worker 负责抓取并写入
📌 Web API 和回测引擎都从这里读
📌 15min 数据会随时间积累（解决 60 天限制）
🔵 Phase 1 — strategies / backtests / price_cache 🟡 Phase 2 — portfolios / positions / trades / notifications
